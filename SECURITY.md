# Security Policy

## Supported Versions
Security updates are applied to the active main branch:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Openbill Pay System handles financial logic, payment reconciliation, and webhook signatures. We take security seriously.

If you discover a security vulnerability (such as a signature bypass, timing attack, race condition, or unauthorized data exposure):

1. **Do NOT open a public GitHub Issue.**
2. Send an email to the repository maintainer or open a private GitHub Security Advisory.
3. Include:
   - Description of the issue and potential impact.
   - Proof-of-concept script or exact steps to reproduce.
   - Any suggested remediation.

We will acknowledge receipt within 48 hours and work with you to release a security fix before public disclosure.
